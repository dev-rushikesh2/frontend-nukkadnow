# Accessibility Guidelines (WCAG 2.1 AA)

- **Contrast Ratios**: All text and critical UI elements must achieve at least 4.5:1 contrast against background colors.
- **Touch Targets**: Minimum 48x48px interactive touch area on Customer PWA mobile screens.
- **Screen Readers**: Explicit `aria-label`, `aria-live` for order status updates, and semantic HTML (`<main>`, `<header>`, `<nav>`, `<button>`).
- **Focus States**: Visible focus indicator for keyboard and assistive navigation.
- **Localization**: RTL/LTR resilience and full multilingual font support.
