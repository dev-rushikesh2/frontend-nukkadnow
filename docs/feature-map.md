# NukkadNow Frontend Feature Map

## Customer PWA Features
1. `onboarding`: First-time user welcome, locality onboarding, permission requests.
2. `authentication`: Phone number OTP verification, guest browsing switch.
3. `home`: Locality-centric landing, category quick-links, spotlight merchants, active order chip.
4. `location-selector`: GPS auto-detection with fallback manual locality selection for Nagpur pilot.
5. `discovery`: Geospatial seller discovery, category filters, distance badges, search.
6. `categories`: Browse hierarchical food, grocery, homemade, seasonal categories.
7. `merchant-profile`: Store details, operating hours, physical queue status vs order prep time.
8. `product-details`: Product bottom sheet, variant selection, dietary tags, add-to-cart.
9. `cart`: Single-outlet cart constraint, item notes, item quantity adjustments, fee breakdown.
10. `checkout`: Delivery vs scheduled pickup selection, time-slot selection, UPI intent trigger.
11. `payment-result`: Payment verification status, success animation, retry flow on timeout.
12. `orders`: Order history, order status filters, reorder shortcuts.
13. `order-tracking`: Live status stepper, estimated ready time, merchant contact.
14. `pickup-token`: Dynamic digital pickup token, QR code for merchant scanning, pickup code.
15. `merchant-delivery`: Self-delivery tracking, merchant delivery agent notes.
16. `favourites`: Bookmarked local shops and recurring grocery items.
17. `notifications`: In-app push notifications for order progress and locality promotions.
18. `account`: User profile, saved addresses (Home, Work, Other), language switcher.
19. `help-support`: FAQs, dispute submission, direct WhatsApp merchant/support link.

## Merchant Portal Features
1. `onboarding`: Business registration, KYC, FSSAI/GST details, outlet setup.
2. `business-profile`: Store profile, brand banner, address, privacy controls for home makers.
3. `outlets`: Multi-outlet support, outlet switching, outlet operating schedules.
4. `seller-modes`: Home maker, seasonal/pop-up stall, regular retail/kirana, restaurant modes.
5. `dashboard`: Real-time operational overview, today's sales, pending orders, queue capacity.
6. `catalogue`: Product catalog, quick in-stock / out-of-stock toggles, pricing.
7. `variants`: Product variant options (size, weight, flavor, add-ons).
8. `inventory`: Stock management, minimum threshold alerts, stock adjustments.
9. `preorders`: Advance order scheduling, lead-time management, preorder quotas.
10. `batches`: Fresh food batch scheduling (bakery, snacks, fresh meal batches).
11. `order-inbox`: High-priority real-time order queue with audio chime, accept/reject, prep time dial.
12. `walkin-orders`: Quick counter billing for physical walk-in customers with token generation.
13. `queue-board`: Kitchen/prep display board for order assembly and customer display.
14. `capacity-settings`: Max concurrent orders throttle, "busy" mode, temporary order pause.
15. `pickup-slots`: Configurable pickup time windows, slots per interval.
16. `qr-ordering`: Printable table/counter QR codes, storefront marketing material downloads.
17. `delivery-settings`: Merchant self-delivery radius, delivery fee rules, minimum order values.
18. `staff-access`: Role-based PIN access for cashiers, kitchen staff, and managers.
19. `subscriptions`: SaaS subscription tiers, plan benefits, renewal management.
20. `billing`: Platform fee statements, payment settlement reports, GST invoices.
21. `analytics`: Sales trends, peak rush hours, top products, customer repeat rate.
22. `notifications`: Merchant operational alerts, low stock warnings, system updates.
23. `settings`: Thermal receipt printer setup, sound volume, regional language preferences.
