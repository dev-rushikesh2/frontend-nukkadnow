# NukkadNow Design System

## Foundations
- **Color Palette**:
  - Primary: Warm Saffron `#F97316` (inviting, Indian locality feel)
  - Secondary: Deep Slate `#0F172A` (authoritative, high contrast)
  - Accent: Vibrant Amber `#F59E0B`
  - Success: Forest Green `#10B981` (Fulfillment / ready status)
  - Warning: Ochre `#EAB308`
  - Error: Crimson `#EF4444`
  - Surface & Backgrounds: Warm neutrals `#FAFAF9`, `#F5F5F4`
- **Typography**:
  - System font stack with robust Indic script rendering support (Hindi / Marathi / Devanagari).
  - Modern sans-serif: Inter / Plus Jakarta Sans.
- **Spacing Scale**:
  - 4px baseline grid (`--spacing-1: 4px`, `--spacing-2: 8px`, `--spacing-4: 16px`, `--spacing-6: 24px`, `--spacing-8: 32px`).
- **Elevation**:
  - Soft card shadows matching modern mobile standards.
